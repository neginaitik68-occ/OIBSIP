# OIBSIP# Unemployment Analysis using Python

## Project Overview

This project analyzes unemployment data in India using Python.

## Tools and Libraries

* Python
* Pandas
* Matplotlib

## Features

* Data Cleaning
* Statistical Analysis
* Region-wise Unemployment Analysis
* Data Visualization

## Dataset

The dataset contains:

* Region
* Date
* Frequency
* Estimated Unemployment Rate (%)
* Estimated Employed
* Estimated Labour Participation Rate (%)
* Area

## Conclusion

The project identifies unemployment trends across different regions and helps understand regional employment patterns.
